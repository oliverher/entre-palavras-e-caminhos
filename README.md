# Entre Palavras e Caminhos

Coletânea de poemas, pensamentos e passagens guardados ao longo da vida, que um dia viajaram no rodapé de e-mails. O site apresenta os textos em formato de livro, organizados em seis caminhos (temas), com sumário, busca, ajuste de letra e modo escuro.

Acesse: https://oliverher.github.io/entre-palavras-e-caminhos/

Os créditos seguem o documento original. Como muitos destes textos circularam por e-mail, a autoria aparece como "atribuído a"; textos sem crédito aparecem como "autoria desconhecida".
